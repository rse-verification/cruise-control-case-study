# Cruise-control natural-language specification — version 2

## 1. Runnable interface and lifecycle

The module shall provide two parameterless runnables with no return value:

```c
void cruise_control_init(void);
void cruise_control(void);
```

The environment shall call initialization before cyclic execution. Runnable
invocations shall not overlap. Inputs shall
be obtained through RTE read functions and outputs sent through RTE write
functions declared in `headers/Rte_CruiseControl.h`. The runnable interface
shall not expose signal parameters or output pointers.

The module shall own three private persistent state variables: `cruise_speed`,
`cruise_state`, and `cruise_integral`. The RTE owns input signals and published
output signals. Published outputs are not used as controller state.

## 2. Input signals

Reads occur in the following order. Each read returns `Std_ReturnType` and
supplies its value through a pointer only when its status is `RTE_E_OK`.

| Signal | Meaning | Type | RTE read function |
|---|---|---|---|
| CC_INR_01 | Enable | `boolean` | `Rte_Read_Enable_CruiseEnable` |
| CC_INR_02 | Resume | `boolean` | `Rte_Read_Resume_Resume` |
| CC_INR_03 | Set | `boolean` | `Rte_Read_Set_Set` |
| CC_INR_04 | QuickDecel | `boolean` | `Rte_Read_QuickDecel_QuickDecel` |
| CC_INR_05 | QuickAccel | `boolean` | `Rte_Read_QuickAccel_QuickAccel` |
| CC_INR_06 | Accelerator pedal | `float32` | `Rte_Read_Accelerator_Accelerator` |
| CC_INR_07 | Brake pedal | `float32` | `Rte_Read_Brake_Brake` |
| CC_INR_08 | Vehicle speed | `float32` | `Rte_Read_SpeedIn_VehicleSpeed` |

Enable is a level signal: true enables cruise control and false disables it.
Speeds are measured in kilometres per hour and pedal values in percent.

## 3. Output signals

Writes occur in the following order. Each write takes a value and returns
`Std_ReturnType`.

| Signal | Meaning | Type | RTE write function |
|---|---|---|---|
| CC_OUTR_01 | Stored cruise speed | `float32` | `Rte_Write_CruiseSpeedOut_CruiseSpeed` |
| CC_OUTR_02 | Throttle command in percent | `float32` | `Rte_Write_ThrottleOut_ThrottleCommand` |
| CC_OUTR_03 | Cruise state | `CruiseState` | `Rte_Write_CruiseStateOut_CruiseState` |

The state values are CRUISE_OFF, CRUISE_ON, CRUISE_STDBY, and CRUISE_INT.

## 4. RTE status behavior

- **CC_HLR_IO_01:** Each cyclic invocation shall read the inputs in the order
  listed in section 2. A successful invocation reads every input exactly once
  before calculating the next controller state or attempting output writes.
- **CC_HLR_IO_02:** On the first read status other than `RTE_E_OK`, execution
  shall return without further reads, without changing persistent controller
  state, and without attempting any output writes. Unsuccessful read values
  shall not be used.
- **CC_HLR_IO_03:** After all reads succeed, the control requirements below shall
  be applied once. The module shall then attempt every output write exactly
  once in the order listed in section 3.
- **CC_HLR_IO_04:** A successful write updates that RTE output with the supplied
  value. A failed write leaves that published output unchanged. Each output is
  written independently; a failure shall not suppress later writes, retry a
  write, or roll back the calculated controller state.
- **CC_HLR_IO_05:** Initialization shall reset private state, then attempt the
  three output writes once in output order, with zero speed, zero throttle, and
  CRUISE_OFF. It shall not read any inputs. Failed initialization writes follow
  CC_HLR_IO_04.

The RTE environment shall return from each read and write call. Signal values
and configured statuses are stable within an invocation. The runnables do not
return transport status; there is no transactional output update or retry policy.

## 5. Parameters

| Parameter | Value |
|---|---:|
| SpeedMin | 30.0 |
| SpeedMax | 150.0 |
| SpeedInc | 2.5 |
| Kp | 8.113 |
| Ki | 0.5 |
| ThrottleSatMax | 45.0 |
| PedalsMin | 3.0 |

## 6. Control requirements

The following requirements apply to cyclic invocations in which every input
read succeeds. References to the current or resulting state refer to private
controller state, irrespective of whether subsequent output writes succeed.

### 6.1 Cruise-control behavior

Speed is within limits when SpeedMin <= speed <= SpeedMax. A pedal is pressed
when its value is strictly greater than PedalsMin.

State-transition priority is Disable, then braking, then waiting in INT for
Resume, then the speed and accelerator eligibility conditions.

- **CC_HLR_CCB_01:** Initialization shall set private cruise state to CRUISE_OFF.
- **CC_HLR_CCB_02:** While enabled, the resulting state shall be CRUISE_ON,
  CRUISE_STDBY, or CRUISE_INT.
- **CC_HLR_CCB_03:** When Enable is false, the resulting state shall be CRUISE_OFF.
- **CC_HLR_CCB_04:** When enabled, not braking, and not waiting in INT for
  Resume, the resulting state shall be CRUISE_ON if the accelerator is not
  pressed and speed is within limits.
- **CC_HLR_CCB_05:** Under those conditions, a pressed accelerator or speed
  outside the limits shall select CRUISE_STDBY.
- **CC_HLR_CCB_06:** STDBY shall return to ON when the accelerator is released
  and speed returns within limits, subject to the higher-priority conditions.
- **CC_HLR_CCB_07:** When enabled and braking, the resulting state shall be
  CRUISE_INT.
- **CC_HLR_CCB_08:** Resume takes effect only while enabled, from a previous INT
  state, without braking. Successful Resume selects ON or STDBY from the
  eligibility conditions and preserves the stored target ahead of all speed
  buttons. A blocked Resume request does not suppress normal speed management.

### 6.2 Driving control

- **CC_HLR_CDC_01:** While OFF, the throttle command shall equal the accelerator
  sensor value above PedalsMin and shall otherwise be zero.
- **CC_HLR_CDC_02:** While ON, cruise control shall regulate speed automatically.
- **CC_HLR_CDC_03:** Every ON cycle, including entry, shall calculate the PI
  candidate as `Kp * error + Ki * (integral + error)`, where error is the updated
  stored target minus vehicle speed. The candidate includes the current error
  even if the integral is held afterward.
- **CC_HLR_CDC_04:** While not ON, the integral shall reset to zero. While ON,
  candidate output at or below zero or at or above ThrottleSatMax shall hold the
  integral; otherwise the integral shall accumulate the current error.
- **CC_HLR_CDC_05:** Automatic throttle shall be clamped between zero and
  ThrottleSatMax. STDBY and INT shall request zero throttle.

### 6.3 Target-speed management

The following rules apply while enabled, except during successful Resume.

- **CC_HLR_CSM_01:** While disabled, stored target speed shall be retained.
- **CC_HLR_CSM_02:** SET shall store the current vehicle speed, bounded to the
  enabled target range.
- **CC_HLR_CSM_03:** QuickAccel shall add SpeedInc when the target is below
  SpeedMax, clamping the result to SpeedMax. Reaching the maximum exactly is
  permitted.
- **CC_HLR_CSM_04:** QuickDecel shall subtract SpeedInc when the target is above
  SpeedMin, clamping the result to SpeedMin.
- **CC_HLR_CSM_05:** The enabled target shall remain between SpeedMin and SpeedMax.
- **CC_HLR_CSM_06:** Simultaneous speed-button priority shall be SET, QuickAccel,
  then QuickDecel. Resume while braking does not override this priority.

### 6.4 Pedal detection

- **CC_HLR_PPD_01:** Accelerator pressed means its value exceeds PedalsMin.
- **CC_HLR_PPD_02:** Brake pressed means its value exceeds PedalsMin.

## 7. Interface and state restrictions

Only the two public runnable entries shall be externally visible. Helpers,
if present, shall be private. The only permitted external function calls are
the RTE functions declared in `cruise_control.is`.

Private target and integral are floating-point values, and private cruise state
has type CruiseState. Initialization resets all three. Input storage and RTE
output storage shall not be used as substitute persistent module state.

The formal specification records the numeric proof domain and verification-only
RTE call counters. These counters describe call attempts, not additional runtime
controller state.
